// How to compile(make) and run:

1. In a terminal, navigate to the directory that contains the game.
command: cd os 
2. Open at least 3 more terminal windows(one for each client), there should be 4 windows (1 server + 3 clients)
3. In each terminal, make sure you’re in the game directory, then compile:
command: make
4. In the terminal you choose as the server, run:
command: ./server
5. In the remaining windows, type the following command to run the clients:
command: ./client
